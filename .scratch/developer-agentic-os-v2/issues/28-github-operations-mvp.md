# 28: GitHub Operations MVP

**What to build:** Let the developer inspect the active repository's GitHub Issues, Pull Requests, Actions, and merge status from the command centre using local environment credentials.

**Blocked by:** 27: Integration Health Foundation

**Status:** ready-for-agent

- [x] GitHub Issues are visible for the active Repository Context.
- [x] Pull Requests show enough state to understand review and merge readiness.
- [x] GitHub Actions status identifies successful, running, and failed automation.
- [x] Merge status is visible and distinguishes ready, blocked, and unavailable states.
- [x] Missing, invalid, rate-limited, and unavailable GitHub credentials produce actionable normalized states.
- [x] Deterministic adapter, route, and browser tests cover success and provider failure behavior.

**Status:** completed
